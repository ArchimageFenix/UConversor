# Fuentes científicas y normativas

Este proyecto no trata los factores de conversión como constantes anónimas.
Cada unidad conserva metadatos de procedencia en su catálogo.

Fuentes iniciales:

1. BIPM — *The International System of Units (SI), 9th edition, version 4.01*.
   https://www.bipm.org/en/publications/si-brochure
2. NIST — *SI Units – Length* (definición internacional de pulgada/yarda).
   https://www.nist.gov/pml/owm/si-units-length
3. NIST — *Guide to the SI, Appendix B: Conversion Factors*.
   https://www.nist.gov/pml/special-publication-811

## Política

- Se privilegian definiciones BIPM/SI e ISO/IEC cuando sean aplicables.
- Para unidades no SI se usan fuentes metrológicas oficiales como NIST o las tablas del BIPM.
- Toda fórmula propia futura deberá documentar derivación, dominio y pruebas.
